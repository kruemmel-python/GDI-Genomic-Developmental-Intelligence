# R17 Supported Scope and Limits

Supported and executed:

- CMake C++20 projects with a successful R15 baseline.
- Isolated addition of a generated component, CMake target integration and native CTest acceptance target.
- Persistent string state with integrity rejection, and integer-sequence aggregation.
- Requirement, strategy and experience persistence.

Not claimed:

- Arbitrary natural-language interpretation, arbitrary source transformation, arbitrary C++20 semantics, or general Rust/Go synthesis.
- Writeback into foreign originals, mutation of generated KR_BUILD artifacts, or bypassing an unreproduced baseline.
- Full scientific blind-transfer validation; that is explicitly deferred by the R17 order.

Unsupported or uncertain requirements return `BLOCKED`/`INCOMPLETE`, rather than generated speculative code.
